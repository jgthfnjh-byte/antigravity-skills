# Специфика КОМПАС-3D Учебная версия (Study Edition)

КОМПАС-3D Учебная версия (KOMPAS-3D Study Edition) предназначена для школьников, студентов и преподавателей. С точки зрения автоматизации и программного интерфейса (API) она обладает практически полной функциональностью профессиональной версии, однако имеет ряд специфических технических особенностей.

---

## 1. Имя исполняемого файла (`kStudy.exe`)

В коммерческой версии КОМПАС-3D главный файл называется `KOMPAS.exe` (или `kHome.exe` в версии Home).
В **Учебной версии** главный исполняемый файл называется:

```text
C:\Program Files\ASCON\KOMPAS-3D v<XX> Study\Bin\kStudy.exe
```

Невидимый процесс для фонового рендеринга и конвертации:
```text
C:\Program Files\ASCON\KOMPAS-3D v<XX> Study\Bin\ksInvisible.exe
```

> [!IMPORTANT]
> Если скрипт пытается вызвать `subprocess.Popen(["KOMPAS.exe", ...])`, он упадет с ошибкой `FileNotFoundError`.
> Используйте `win32com.client.Dispatch("KOMPAS.Application.7")` или поиск через системный реестр, реализованный в `kompas_tool.py`: Windows сама найдет `kStudy.exe` по зарегистрированному COM GUID.

## 2. Разрядность (64-bit)

Начиная с версии v18, КОМПАС-3D выпускается исключительно в 64-битном варианте:
- Интерпретатор Python **обязан** быть 64-битным (`win_amd64`).
- При попытке подключения из 32-битного Python возникнет ошибка `Class not registered` или сбой загрузки DLL `ksAPICLink.dll` / `ksAPI.dll`.
- Для проверки разрядности:
  ```powershell
  python -c "import platform; print(platform.architecture())"
  # Ожидаемый вывод: ('64bit', 'WindowsPE')
  ```

---

## 3. Ограничения форматов файлов и лицензирования

1. **Метка Учебной версии**:
   Все сохраненные чертежи (`.cdw`), 3D-детали (`.m3d`) и сборки (`.a3d`) помечаются флагом учебной версии.
2. **Водяной знак**:
   При экспорте в PDF или выводе на печать в углу листа автоматически выводится нестираемая надпись «КОМПАС-3D Учебная версия».
3. **Совместимость с коммерческой версией**:
   Файлы, созданные в коммерческой версии, открываются в Учебной версии свободно. Файлы Учебной версии открываются в коммерческой версии с предупреждением и сохранением учебного статуса.
4. **Доступность API**:
   Все методы API7 и API5 (создание геометрии, размеров, видов, сечений, спецификаций, 3D-выдавливания, экспорта в STEP, STL, PDF, DXF) функционируют **без каких-либо искусственных ограничений**.

## 4. Диагностика неполадок

Если КОМПАС-3D не отвечает или зависает:

1. **Проверьте запущенные процессы**:
   ```powershell
   Get-Process -Name "kStudy*", "ksInvisible*"
   ```
2. **Завершение зависшего фонового процесса**:
   Если при предыдущих запусках остался "зависший" невидимый процесс:
   ```powershell
   Stop-Process -Name "kStudy", "ksInvisible" -Force -ErrorAction SilentlyContinue
   ```
3. **Запуск самодиагностики навыка**:
   ```powershell
   python "C:\Users\jgthfnjh\.gemini\config\skills\kompas-3d\scripts\kompas_tool.py" doctor
   ```
