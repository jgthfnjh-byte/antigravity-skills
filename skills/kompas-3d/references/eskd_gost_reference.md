# Справочник по ГОСТ и ЕСКД для КОМПАС-3D

При создании чертежей в КОМПАС-3D важно строго соблюдать стандарты Единой системы конструкторской документации (ЕСКД).

---

## 1. Форматы листов (ГОСТ 2.301-68)

| Обозначение | Размеры (мм) | Разрешенная ориентация | Код в КОМПАС API |
| :--- | :--- | :--- | :--- |
| **A4** | 210 × 297 | **Только вертикальная** (по стандарту ЕСКД) | `4` |
| **A3** | 297 × 420 | Горизонтальная (предпочтительно) / Вертикальная | `3` |
| **A2** | 420 × 594 | Горизонтальная / Вертикальная | `2` |
| **A1** | 594 × 841 | Горизонтальная / Вертикальная | `1` |
| **A0** | 841 × 1189 | Горизонтальная / Вертикальная | `0` |

### Поля чертежа:
- Левое поле: **20 мм** (для брошюровки/подшивки).
- Верхнее, правое, нижнее поля: **5 мм**.

## 3. Масштабы (ГОСТ 2.302-68)

- **Масштаб натуральной величины**: `1:1`
- **Масштабы уменьшения**: `1:2`, `1:2.5`, `1:4`, `1:5`, `1:10`, `1:15`, `1:20`, `1:25`, `1:40`, `1:50`
- **Масштабы увеличения**: `2:1`, `2.5:1`, `4:1`, `5:1`, `10:1`, `20:1`, `40:1`, `50:1`, `100:1`

## 4. Типы линий (ГОСТ 2.303-68)

| Тип линии | Назначение | Толщина | Стиль в КОМПАС API |
| :--- | :--- | :--- | :--- |
| **Сплошная толстая (основная)** | Линии видимого контура, границы сечений | $s = 0.5 \dots 1.4$ мм | `ksCSNormal` (1) |
| **Сплошная тонкая** | Размерные и выносные линии, штриховка | $s/3 \dots s/2$ | `ksCSThin` (2) |
| **Штрихпунктирная тонкая (осевая)** | Осевые и центровые линии | $s/3 \dots s/2$ | `ksCSAxial` (3) |
| **Штриховая** | Линии невидимого контура | $s/3 \dots s/2$ | `ksCSDotted` (4) |
| **Сплошная волнистая** | Линии обрыва, разграничение вида и разреза | $s/3 \dots s/2$ | `ksCSBroken` |

---

## 5. Стандартные шероховатости (ГОСТ 2.309-73)

Ряд предпочтительных значений параметра $Ra$ (в мкм):
- Грубая обработка (литье, прокат без обработки): $Ra \ 25$, $Ra \ 12.5$
- Черновая механическая обработка: $Ra \ 6.3$
- Получистовая обработка: $Ra \ 3.2$
- Чистовая обработка (посадочные поверхности, скольжение): $Ra \ 1.6$, $Ra \ 0.8$
- Высокоточная доводка, шлифование: $Ra \ 0.4$, $Ra \ 0.2$
