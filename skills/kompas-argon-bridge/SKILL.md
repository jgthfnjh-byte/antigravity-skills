# Навык: Мост КОМПАС-3D ↔ Gemini 4 Argon (Google AI Studio)

## Назначение
Этот навык активируется, когда пользователь просит спроектировать деталь, эскиз или чертеж в КОМПАС-3D (как сложную, так и типовую).
Навык предлагает пользователю гибридный рабочий процесс:
1. **Gemini 4 Argon** (в Google AI Studio) рассчитывает сложную математику, тригонометрию, сечения и координаты.
2. **Antigravity (агент)** принимает результат работы Argon и физически строит модель в локальном КОМПАС-3D через `kompas_tool.py`.

---

## 🛠️ Алгоритм действий агента при запросе на моделирование

Когда пользователь обращается с задачей создания детали/чертежа в КОМПАС-3D:

1. **Предложить синергию с Argon в Google AI Studio**:
   Сообщите пользователю, что для точного расчета геометрии, формул, сопряжений и координат точек отлично подойдет модель **Gemini 4 Argon** в Google AI Studio.

2. **Предоставить 2 формата вывода для Argon**:
   - **Формат 1: JSON-спецификация** (готовая для прямой сборки через `kompas_tool.py build --spec ...`).
   - **Формат 2: Массив математических координат / формулы** (для криволинейных контуров, лопаток, кулачков, эвольвент и сплайнов).

3. **Предоставить готовый шаблон промпта** для вставки в Google AI Studio.

4. **Предложить альтернативу прямого построения**:
   Уточните, что если пользователь хочет сделать всё сразу в один шаг без перехода в AI Studio, агент может построить деталь немедленно своими силами через `kompas_tool.py`.

## 📋 Форматы данных для Argon

### Вариант 1: Декларативная JSON-спецификация
Идеально для деталей с операциями выдавливания (`extrude`), вырезания (`cut`), вращения и типовыми фигурами (окружности, прямоугольники, отверстия):

```json
{
  "type": "part",
  "title": "Наименование детали",
  "code": "ШИФР.001.00",
  "operations": [
    {
      "type": "extrude",
      "plane": "XOY",
      "depth": 25.0,
      "sketch": [
        {"type": "rect", "x1": -50, "y1": -30, "x2": 50, "y2": 30}
      ]
    },
    {
      "type": "cut",
      "plane": "XOY",
      "depth": 25.0,
      "sketch": [
        {"type": "circle", "xc": 0, "yc": 0, "radius": 15}
      ]
    }
  ]
}
```

### Вариант 2: Массив координат точек / контур сплайна
Идеально для сложных аэродинамических профилей, кулачковых механизмов, зубчатых колес и математических кривых:

```python
# Координаты сечения детали:
profile_points = [
    (0.0, 0.0),
    (10.5, 3.2),
    (24.8, 8.7),
    (42.0, 12.1),
    (60.0, 11.4),
    (78.5, 7.3),
    (95.0, 2.1),
    (100.0, 0.0)
]
# Глубина выдавливания: 15.0 мм, плоскость: XOY
```

## 📝 Шаблон промпта для Google AI Studio (Argon)

```markdown
Спроектируй деталь для КОМПАС-3D: [НАЗВАНИЕ И ОПИСАНИЕ ДЕТАЛИ].
Рассчитай точные геометрические размеры, толщины стенок, координаты и радиусы.
Выдай ответ строго в одном из двух форматов (без длинных вступительных рассуждений):
- Либо валидная JSON-спецификация с операциями extrude/cut и эскизами (circle, rect, line);
- Либо массив координат замкнутого контура точек points = [(x, y), ...] с указанием плоскости (XOY/XOZ/YOZ) и глубины выдавливания.
```

## ⚡ Действия агента при получении ответа от Argon

Как только пользователь вставляет в чат вывод от Argon:
1. Сохранить спецификацию во временный файл `spec.json` или создать скрипт построения контура по точкам.
2. Выполнить команду сборки:
   ```powershell
   python "C:\Users\jgthfnjh\.gemini\config\skills\kompas-3d\scripts\kompas_tool.py" build --spec spec.json --output part.m3d --export part.step
   ```
3. Если передан массив точек — сгенерировать скрипт с `KompasSession` и `doc.add_polyline` / `doc.add_spline`, выдавить эскиз и сохранить `.m3d`.
4. Сообщить пользователю об успешном создании детали и предоставить прямые ссылки на полученные файлы (`.m3d`, `.cdw`, `.step`, `.pdf`).
